ditto is a cross-platform and system-wide keyboard visualizer and keycaster in the terminal that works even when it isn't in focus. automatically syncs with your native terminal color scheme. intended for folks who want to prettify their terminal setup. if you like it, a ⭐ is appreciated!

install via the [releases](https://github.com/arvingarciabtw/ditto/releases) or with go:

```sh
go install github.com/arvingarciabtw/ditto/cmd/ditto@latest
```

for linux users, there are also other [installation](https://ditto.arvingarcia.com/installation) options over at the docs.

## docs

docs have been moved to the [website](https://ditto.arvingarcia.com), you can find more information like usage options over there.

## contributing

contributions are welcome!

as i kept developing this program, i've learned that keyboards actually get pretty deep. for instance, check out this [list](https://en.wikipedia.org/wiki/List_of_QWERTY_keyboard_language_variants) of qwerty keyboard language variants. if you'd like to add a specific layout variant to the layout list, i'd appreciate a pull request or opening up an issue about it.
